Section 05 · Data notes

Where the pictures come from

Time Lab shows public SPHEREx spectral images served by the NASA/IPAC Infrared Science Archive (IRSA). Nothing is stored on this site; every frame is fetched live.

Mission

SPHEREx

NASA’s Spectro-Photometer for the History of the Universe, Epoch of Reionization and Ices Explorer, launched in March 2025.

Survey

Whole sky every six months

Each part of the sky is revisited about twice a year, which is what makes motion and variability visible.

Colours

102 infrared bands

From 0.75 to 5.0 µm, sensitive to water, carbon dioxide and carbon monoxide ices and to cold, dim objects.

The six detectors

SPHEREx uses linear variable filters: the wavelength changes smoothly across each detector. A star lands in a different narrow band every time the telescope points at it.

DetectorWavelength rangeGood for
D10.75–1.09 µmStars, galaxies, matching optical surveys
D21.10–1.62 µmStars, galaxies, cool dwarfs
D31.63–2.41 µmDusty and embedded stars
D42.42–3.82 µmWater ice, hydrocarbons
D53.83–4.41 µmCarbon dioxide ice, cold brown dwarfs
D64.42–5.00 µmCarbon monoxide, the coldest brown dwarfs

How the Time Lab reads the archive

  1. Search. The viewer asks IRSA’s Simple Image Access service (SIA v2) for every SPHEREx spectral image that contains your position.
  2. Cut out. For each image it requests only a small square around your position from IRSA’s cutout service, instead of the full multi-hundred-megabyte file.
  3. Read. A small FITS reader in the browser reads the IMAGE and FLAGS extensions and, when asked, the WCS-WAVE wavelength table. It stops downloading as soon as those parts have arrived.
  4. Align. Each cutout’s world coordinate system, including its distortion terms, is used to resample it onto a common north-up grid.

Keeping up with new releases

SPHEREx data arrives quickly: weekly quick releases, followed by larger, fully processed data releases. Time Lab always asks the archive live, so new images in an existing collection show up automatically. When IRSA opens a new collection, add one line to config.js:

collections: [
  { id: 'spherex_dr1', label: 'Data Release 1' },   // new release first
  { id: 'spherex_qr',  label: 'Quick Release · Wide Survey' },
  ...
]

The first entry becomes the default. If it has no images for a position, the viewer falls back to the next collection automatically.

Quality flags

Every SPHEREx image comes with a flag map that marks saturated, hot, cosmic-ray-hit or otherwise unreliable pixels. Time Lab can shade any flagged pixel and lists the flag bits at the pixel you click. The meaning of each bit is in the SPHEREx Explanatory Supplement.

Credits and citation

This work uses data from SPHEREx, a NASA mission, served by the NASA/IPAC Infrared Science Archive. Reference stars come from the European Space Agency’s Gaia mission (Data Release 3) and from AllWISE via the VizieR service. The interactive atlas is Aladin Lite and name look-up uses Sesame, both from CDS, Strasbourg. If you publish results based on SPHEREx data, follow IRSA’s acknowledgement and citation guidance for the release you used.
